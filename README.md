# 이태현 Portfolio

SM엔터테인먼트 · 중화권 아티스트 전담 영상 콘텐츠 제작 인턴십 지원용 포트폴리오.

정적 사이트입니다. `index.html`이 진입점이고, 별도 빌드 과정이 없습니다.

## GitHub Pages로 공개하기
1. 이 폴더를 GitHub Desktop에서 새 저장소로 만들고 Publish (Public).
2. github.com 저장소 → Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/ (root)` → Save.
3. 1~2분 후 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

`.nojekyll` 파일은 `_ds` 폴더(디자인 시스템 토큰·번들)가 무시되지 않게 하는 용도이므로 삭제하지 마세요.
