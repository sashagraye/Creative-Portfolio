# New Form — Design System

간단 포트폴리오용 디자인 시스템. 원본 스타일 레퍼런스는 **New Form**("editorial broadsheet in a green room") — 인쇄된 금융 브로드시트를 웹으로 옮긴 듯한 톤이다. 페이지는 압도적으로 타이포그래피 중심이고, 사진은 그레이스백 듀오톤 타일로 텍스트 흐름을 끊는 삽화처럼만 등장한다. 채도 있는 색은 형광 초록 하나뿐이며, 마커로 그은 것처럼 쓴다.

이번 스코프는 **홈 히어로 섹션 한 개**다. 스크롤 애니메이션은 아직 넣지 않았다.

## 소스

| 소스 | 경로 | 역할 |
|---|---|---|
| `uploads/DESIGN (4).md` | 프로젝트 파일 | 구조·컴포넌트 명세. 폰트/타입 스케일 값은 참조하지 않는다 |
| `uploads/tokens_1.css` | 프로젝트 파일 | **단일 소스.** `tokens/tokens.css`로 옮겨 사용 |

Figma 링크, GitHub 저장소, 코드베이스는 제공되지 않았다. 로고 파일도 없다.

### 규칙 (하드 제약)
1. 색·크기·간격은 전부 `tokens/tokens.css`의 변수를 참조한다. 컴포넌트에 hex·px 직접 기입 금지.
2. `DESIGN.md`와 `tokens.css`가 충돌하면 **tokens.css가 이긴다** (폰트·타입 스케일이 여기 해당).
3. `DESIGN.md`의 "Don't" 목록은 하드 제약이다. 아래 VISUAL FOUNDATIONS에 다시 적었다.

## 인덱스

- `styles.css` — 컨슈머가 링크하는 단일 진입점. `@import` 한 줄뿐이다.
- `tokens/tokens.css` — 유일한 소스. 색, 타입, 스페이싱, 반경, 그림자, 서피스, 이미지 필터, 모션 + `.hero-ko` / `.display-ko` / `.heading-ko` / `.display-latin` / `.micro-label` 유틸리티 클래스.
- `components/hero/` — **Hero** (`Hero.jsx`, `Hero.d.ts`, `Hero.prompt.md`, `hero.card.html`).
- `templates/hero-section/HeroSection.dc.html` — **Editorial Hero** 템플릿. 컨슈머 프로젝트가 복사해 시작점으로 쓴다 (`ds-base.js`가 이 시스템의 스타일·번들을 로드).
- `guidelines/*.card.html` — 파운데이션 스펙시멘 카드 14장 (Colors, Type, Spacing, Shape & Effects, Imagery, Brand, Motion).
- `thumbnail.html` — 홈 타일.
- `SKILL.md` — Claude Code용 스킬 엔트리.

### Components
- **Hero** — 홈 히어로 섹션. 상단 내비(워드마크 좌 / 마이크로 라벨 메뉴 우), 한글 헤드라인 타이포그래피 벽, 줄 사이 인라인 사진 타일 2~3개, 하단 primary action 버튼. 템플릿 버전은 `templates/hero-section/`에 있다.

아직 만들지 않은 것: 그 외 프리미티브(버튼·태그·링크 단독 컴포넌트), 다크 에디토리얼 섹션, 풀블리드 액센트 밴드, 푸터, UI 킷, 슬라이드. 스코프가 히어로 하나였다.

## CONTENT FUNDAMENTALS

**목소리.** 자기 홍보가 없다. 무엇을 하는지 평서문으로 짧게 말하고 끝낸다. 형용사보다 동사, 감탄보다 사실.

**한글 헤드라인은 한 줄 5~7자, 3~4줄.** 이게 카피 규칙이면서 동시에 레이아웃 규칙이다. 문장을 먼저 쓰고 자르지 말고, 자를 지점을 정해두고 문장을 쓴다.

```
생각을 정리해
화면으로 옮기는
일을 합니다
```

**마이크로 라벨은 소문자 영문 또는 짧은 한글.** 내비·버튼·태그는 전부 `.micro-label`(11px / 600 / uppercase / +0.06em). 영문이면 `work · about · contact`처럼 단어 하나. 문장을 넣지 않는다.

**본문은 18px를 넘기지 않는다.** 18px 본문과 96px 이상 디스플레이 사이의 크기 격차가 리듬을 만든다. 중간 크기로 메우려 하지 말 것.

**케이싱.** 영문 마이크로 라벨은 대문자 변환(`text-transform`)으로 처리하되, 원문 소스는 소문자로 쓴다. 영문 헤드라인은 Title Case가 아니라 문장 케이스. 한글에 uppercase는 무연산이므로 그대로 둔다.

**나 / 당신.** 1인칭 주어를 생략한다("일을 합니다", "만듭니다"). 독자를 "you"로 부르지 않는다.

**이모지 없음.** 어떤 표면에도 쓰지 않는다. 구분자가 필요하면 `·` 또는 `—`.

**숫자.** 스탯은 장식하지 않는다. newsprint gray에 디스플레이 크기로 놓아 "히어로 숫자"가 아니라 편집면의 데이터처럼 읽히게 한다.

## VISUAL FOUNDATIONS

**컬러.** 모노크롬 캔버스 + 초록 하나. Bone white `#fafffa`가 캔버스다 — 순백 `#ffffff`는 금지이며, 이 미세한 온기가 일반 SaaS 표면과 이 페이지를 갈라놓는다. 잉크는 press black `#121613`(초록 쪽으로 살짝 기운 근사 블랙). 뉴트럴은 전부 초록 기미가 있다(newsprint gray, muted sage, echo green, shadow moss). 채도색은 highlighter green `#2bee4b` 단 하나이고, 교체 진입점은 `--color-accent` 한 곳이다. **두 번째 채도색을 추가하지 않는다.**

**타입.** 유료·한글 미지원 문제로 원문 3종을 교체했다(아래 폰트 대체 항목). 전역은 **Pretendard**, 라틴 포인트 서체는 **Instrument Serif**. 한글 디스플레이는 크기로 밀지 않고 "한 줄 5~7자 × 3~4줄"의 벽으로 만든다(`--text-ko-hero` 140px가 상한). 라틴 단독 조판에서만 원문의 극단 스케일(155~295px, 행간 0.9, 자간 -0.04em)을 그대로 쓴다. 한글 본문 행간은 1.6, 원문의 1.0은 라틴 전용이다. `word-break: keep-all`로 어절 단위 줄바꿈.

**스페이싱.** 4~190px의 이산 스케일. 밀도는 여유롭다 — 섹션 간격 80px, 요소 간격 20px, 카드 패딩 0px. 콘텐츠 폭은 1400px를 넘지 않는다.

**배경.** 색면만. 3단 서피스(canvas / dark section `#121613` / accent band `#2bee4b`)뿐이고, 그라디에이션·텍스처·패턴·손그림 일러스트는 없다. 배경 이미지도 없다 — 풀블리드 히어로 사진 금지.

**이미지.** 모든 사진은 `--filter-duotone` 한 체인을 통과한다(grayscale → invert 0.27 → sepia 0.07 → saturate 10.67 → hue-rotate 80deg → brightness 1.02 → contrast 0.83). 결과는 원본과 무관하게 초록 계열 2톤. 색감은 차갑고 그레인 없음. 크롭은 200×140px 안팎의 작은 사각 타일, 반경 14px, **그리드가 아니라 디스플레이 텍스트 줄 사이 인라인**. 라이프스타일 사진 금지, 다큐멘터리 톤만.

**보더.** 헤어라인 1px, 있거나 없거나. 구조는 타이포그래피와 여백이 만든다. 워드마크 밑줄만 2px 초록.

**반경.** 버튼 5px, 필 10px, 이미지 14px, 원형 9999px. **primary action에 필/원형 금지** — 5px의 각이 편집면 톤을 유지한다.

**그림자.** 딱 하나, primary action에만. `rgba(16,94,29,0.45) 1px 8px 20px 0`으로 초록이 밖으로 번진다. 회색 드롭섀도 금지. **카드·섹션·이미지에는 box-shadow를 쓰지 않는다.** 카드는 그림자도 보더도 없는 평면이며, 카드 패딩은 0이다.

**투명도·블러.** 쓰지 않는다. 보호 그라디에이션, 프로스트 캡슐, 백드롭 블러 모두 없음 — 텍스트는 항상 불투명 색면 위에 놓인다.

**모션.** 원문에 정의가 없어 이 시스템에서 정의했다. 이징은 `cubic-bezier(0.16, 1, 0.3, 1)`(감속만, 바운스·오버슈트 없음), 지속시간 240 / 600 / 1000ms, 줄 단위 지연 70ms. 현재 히어로에는 hover/press 마이크로 인터랙션만 들어가 있고 스크롤 애니메이션은 없다.

**hover.** 색을 바꾸지 않는다. primary action은 4px 떠오르고 그림자가 `--shadow-lg-2`(더 옅은 초록)로 바뀐다. 링크는 밑줄만으로 상태를 표현하고 굵기·색을 바꾸지 않는다.

**press.** 떠오른 것이 제자리로 내려앉는다(translateY 0). 축소·색 변화 없음.

**레이아웃.** 1400px 상한, 좌우 거터 50px. 고정 요소 없음 — 내비는 sticky가 아니라 페이지 흐름 안에 있다. 세로로 읽히는 브로드시트이지 대시보드가 아니다.

### 폰트 대체 — 확인 필요
원문 3종(TWK Lausanne / PP Mondwest / Editorial New)은 전부 유료 라이선스이고 한글 글리프가 없다. 업로드된 `tokens.css`가 이미 다음으로 대체해 두었고, 그 결정을 그대로 따랐다:
- 전역 → **Pretendard Variable** (jsDelivr CDN, dynamic subset)
- 라틴 디스플레이 → **Instrument Serif** (Google Fonts)
- Editorial New는 사용하지 않음 (디스플레이 서체 2종으로 축소)
- 원문 weight 550 → Pretendard 600으로 매핑

두 폰트 모두 CDN에서 원격으로 불러온다. 프로젝트에 폰트 바이너리는 없다. 오프라인 번들이 필요하면 `.woff2` 파일을 주면 `@font-face`로 바꿔 넣는다.

## ICONOGRAPHY

**제공된 아이콘 자산이 없다.** 아이콘 폰트, 스프라이트, SVG 세트 모두 소스에 없었다. 원문 명세가 말하는 아이콘 방침은 다음 한 줄뿐이다: "최소한의 스트로크 마크, `#000000` 또는 `#fafffa`, 멀티컬러 아이코노그래피 없음."

그래서 이 시스템은 현재 **아이콘을 하나도 쓰지 않는다.**
- Hero의 primary action은 라벨만 있다. 원문 예시에는 라벨 오른쪽 화살표가 있지만, 소스에 실제 마크가 없어 임의로 그리지 않았다.
- 내비의 "Menu 3-bar 초록 아이콘"도 같은 이유로 넣지 않고 텍스트 메뉴로 두었다.
- 이모지, 유니코드 기호(→, ↗ 등)를 아이콘 대용으로 쓰지 않는다. 구분자로서의 `·` `—`만 허용.

**필요한 것.** 실제 아이콘 파일(SVG 세트)을 주면 `assets/icons/`에 넣고 Icon 래퍼를 만든다. 없다면 스트로크 1px, 라운드 캡의 CDN 세트(Lucide) 중 최소 계열로 대체할 수 있는데, 이건 대체이므로 승인이 필요하다.

`assets/` 폴더는 비어 있다 — **로고 파일이 제공되지 않았으므로 로고를 만들지 않았다.** 워드마크가 필요한 자리에는 Instrument Serif 활자로 "New Form"을 조판하고 "New" 아래에 2px 초록 밑줄을 넣는다. 이 밑줄이 로고 처리의 전부다.
